# 🧠 Lex’s Core Python Lab

**Foundational exercises before neural nets.**

---

## 🎯 Purpose

This folder is dedicated to rebuilding my Python fluency from the ground up — the first phase of my AI Engineer Journey.  
I’ll focus on writing clean, readable code and developing an intuitive feel for logic, loops, data structures, and file handling before moving into machine learning.

---

## 📚 Topics Covered

- Python Basics → variables, functions, conditionals, loops
- Data Structures → lists, tuples, dictionaries, sets
- File I/O → reading/writing files, JSON, CSV
- Error Handling → try/except, raising custom errors
- Object-Oriented Programming → classes, inheritance, magic methods
- Practice Projects → small, self-contained projects to apply everything learned
